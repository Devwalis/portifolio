Projeto Social CDD 4.0 - Dia das Crianças

Site desenvolvido para integrar equipes e apresentar ações sociais

Durante o curso CDD 4.0, desenvolvemos um site estático em HTML, CSS e JavaScript com o objetivo de reunir os resultados das equipes participantes. O projeto, construído em parceria com Caio Marinho, teve como foco a prática de lógica de programação e o fortalecimento das soft skills por meio de uma ação social no Dia das Crianças.

Prática de Front-end: Efeitos Visuais com Parallax

Aplicação de conceitos modernos de UI/UX com HTML, CSS e JavaScript

Projeto desenvolvido no curso técnico de Desenvolvimento de Sistemas com o objetivo de praticar técnicas avançadas de front-end. Para atingir o efeito parallax, foram utilizadas propriedades CSS como `background-attachment: fixed` e manipulação de camadas em diferentes velocidades de rolagem. O trabalho avaliativo envolveu a construção de um site responsivo, aplicando boas práticas de semântica, acessibilidade e design visual.

Raízes da Educação: Desenvolvimento Colaborativo com SCRUM

Aplicação de metodologias ágeis no desenvolvimento de sistemas educacionais

Projeto integrador realizado no curso de Programador de Sistemas do SENAC. A proposta envolveu o desenvolvimento de uma aplicação web com Django (Python), HTML, CSS e JavaScript, em um ambiente colaborativo. Utilizamos práticas ágeis com SCRUM, sprints semanais e Kanban para organização das atividades. O projeto teve como objetivo a criação de uma plataforma para integrar iniciativas educacionais e fomentar o trabalho em equipe com versionamento no GitHub.
